# Customer-Shopping-Behavior-Analysis
An end-to-end data analytics project using Python, SQL, and Power BI to analyze customer shopping behavior and generate actionable business insights.

## 📊 Project Overview

This project explores customer shopping behavior to understand purchasing patterns, product preferences, discount usage, subscription status, and customer demographics.

The workflow includes data exploration and cleaning in Python, business analysis using SQL, and visualization through an interactive Power BI dashboard.

## 📁 Dataset

The dataset contains **3,900 records and 18 original columns**, covering:

- Customer demographics, including age, gender, and location.
- Product categories, purchased items, and seasonal preferences.
- Purchase amounts, previous purchases, and purchase frequency.
- Review ratings, shipping methods, and payment methods.
- Discount usage and subscription status.

## 🛠️ Tools & Technologies

- **Python & Pandas:** Data exploration, cleaning, and preprocessing.
- **Jupyter Notebook:** Interactive data analysis.
- **PostgreSQL & SQL:** Database management and business queries.
- **Power BI:** Dashboard development and data visualization.
- **GitHub:** Project documentation and version control.

## 🔍 Project Workflow

1. **Data Exploration:** Inspect the dataset, data types, summary statistics, and missing values.
2. **Data Cleaning:** Handle missing review ratings, standardize column names, and create additional analytical features.
3. **SQL Analysis:** Analyze purchase amounts, customer segments, product ratings, discount usage, shipping preferences, and subscription behavior.
4. **Power BI Dashboard:** Visualize customer shopping patterns and explore the analysis through the report.
5. **Reporting:** Document findings and identify potential business applications.
